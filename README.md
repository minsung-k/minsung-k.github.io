# minsung-k.github.io

Personal academic homepage, built with Jekyll on GitHub Pages using the
[academic-homepage](https://github.com/luost26/academic-homepage) template (MIT).

Edit `_data/profile.yml` (bio, links, education), add publications in `_publications/`,
news in `_news/`, and posts in `_posts/`. Preview locally: `bundle install && bundle exec jekyll serve`.

Publications live in `_publications/`; set `status:` to `published`, `review`, `preparation` or `talk` to place them in a section.
